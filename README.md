Entri untuk bounty [The Internet in One Word](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b) ($10): rangkum seluruh internet dalam satu kata saja.

> brainrot

Kenapa kata ini? Internet sekarang itu lautan meme absurd, tren
aneh, dan video pendek yang bikin orang scroll terus tanpa sadar
waktu lewat berjam-jam. Otak pelan-pelan "meleleh" — tapi dengan
senang hati, dan besok balik lagi. Satu kata ini menangkap kekonyolan
dan kecanduan itu sekaligus, tanpa perlu penjelasan panjang. Bonus
lucu: "brainrot" sendiri adalah kata yang lahir dari internet, jadi
internet di sini sedang menggambarkan dirinya sendiri.

## Cara menjalankan

```bash
python3 main.py
```

Program menulis `entry.txt` berisi satu kata ke direktori
`$MAKEFUN_OUTPUT_DIR` (kalau variabel itu tidak diset, ke `/output`).
Sebelum menulis, program memeriksa dulu bahwa entrinya benar-benar
satu kata huruf saja — kalau bukan, ia menolak menulis.
